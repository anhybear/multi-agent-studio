# The Multi-Agent Studio

An interactive, single-file learning experience for understanding the **architecture
of multi-agent AI systems** — built for non-coders who want to *direct* coding agents
(Codex, Claude Code, etc.) to build agentic systems well, rather than write the code by hand.

**[→ Open `Multi-Agent-Systems-Academy.html`](Multi-Agent-Systems-Academy.html)** — just
double-click it. No build step, no dependencies, works offline. Progress saves in your browser.

## What's inside

Ten lessons across four parts — from "what is an agent" to running, debugging, and shipping
real systems. Every concept is taught three ways:

1. **The intuition** — plain language + a creative analogy.
2. **The LangGraph translation** — what the idea is *called* in real code.
3. **A director's brief** — a copy-ready prompt to hand a coding agent.

Interactive throughout: clickable pattern diagrams, an architecture decision tree, a
LangGraph **graph tracer**, an **orchestration simulator** (watch agent teams "think"
step by step), a risk classifier, a failure-mode diagnostic, checkpoint quizzes, and a
searchable glossary.

## Sources

Distilled from Victor Dibia's *Designing Multi-Agent Systems* (2025), classic software
design patterns, and current [LangGraph](https://langchain-ai.github.io/langgraph/)
documentation. The book PDF is intentionally **not** included in this repo (copyright).

## Source of truth

This repo is the living version. Update the HTML as frameworks and practices evolve.

## Companion

A mirrored Notion workspace exists for annotating and revisiting, and a portable
agent-architecture **skill** (in `agent-architect-skill/`) lets any coding agent reference
these principles when building new systems.
